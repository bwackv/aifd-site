Final Workshop: Variable Type & Custom Expressive Lettering Breakout

Context: Designed for the final session of the Typography Module in ART 3041: A.I. for Designers (aifordesigners.net).

Prerequisites: Students have live GitHub Pages sites and working poster engines with dynamic data streams (API/JSON data feeds, time-based updates, or interactive controls built during Session 5).

Objective: Replace passive screen-share critique with hands-on breakout sprints. Students will modify their existing poster generators and live sites by injecting expressive variable fonts (font-variation-settings), kinetic CSS animations, and custom AI/vectorized hand-drawn letterforms.

01Sessions Overview

7.2 · Wed Oct 14 · in person

Students select one of the following 3 activities to integrate directly into their live project repository.

02Sprint A

The Variable Data Stream Engine

Goal: Connect live data streams (from Session 5, e.g., weather, time, scroll position, audio input, cursor coordinates) directly to custom variable font axes instead of static CSS properties.

  1. Font Selection: Select a highly responsive variable font from Google Fonts featuring unique custom axes. Examples below, feel free to find others by sorting by variable fonts or finding other free variable fonts on the web.
    • Recursive (CASL Casual, CRSV Cursive, MONO, slnt)
    • Fraunces (WONK Wonkiness, SOFT Softness, opsz Optical Size)
    • Tilt Warp / Tilt Neon / Tilt Prism (XROT X-Rotation, YROT Y-Rotation)
    • Bitcount (Pixel size & grid variation axes)
    • Roboto Flex (12+ fine-grained parametric axes like XTRA, YOPQ, GRAD)
  2. AI Co-Coding Prompting: Instruct Gemini/Claude to refactor (rewrite existing code so it does something new, without starting over) their Session 5 JS engine:

    “Refactor my existing event listener / data fetch function so that as [API Value / Mouse X Pos / Time / Scroll %] changes, it dynamically updates document.documentElement.style.setProperty('--font-axis-val', value) to control CSS font-variation-settings: 'CASL' var(--font-axis-val) on my poster headline.”

  3. Refinement: Ensure transitions are smooth using CSS transition: font-variation-settings 0.1s ease-out.

03Sprint B

Kinetic Typography & CSS Keyframe Loops

Goal: Build keyframed kinetic typography that loops continuously or triggers on hover/click state, creating expressive typographic motion purely through code (no video rendering or After Effects).

  1. Selection: Import expressively dynamic variable fonts like Amstelvar, Decovar, Tilt Prism, Danfo, or Ojuju.
    • Amstelvar: play with the font at v-fonts and download it on GitHub
    • Decovar: play with the font at v-fonts and download it on GitHub
    • Tilt Prism: play with the font at v-fonts and download it on GitHub
    • Danfo: play with the font at Google Fonts and download it on GitHub
    • Ojuju: play with the font at Google Fonts and download it on GitHub
  2. Prompting the AI: Have students prompt their AI co-developer:

    “Write CSS @keyframes that smoothly loop through the font’s custom variation settings over 4 seconds, varying weight from 100 to 900, optical size from 12 to 144, and slant from 0 to -15. Apply this to my hero typographic section on hover.”

  3. Critical Design Check: Discuss legibility vs. spectacle: When does movement add expressive narrative context, and when does it degrade functional hierarchy?

04Sprint C

The Analog-to-Digital Hybrid Glyphs Engine

Goal: Convert physical hand-drawn letterforms or custom sketches into SVG vector assets and embed them alongside responsive variable body type.

  1. Draw (10 mins): Draw 1–3 words or letters on paper with markers, highlighters, tape, or torn paper. Thick, high-contrast marks trace best.
  2. Photograph (2 mins): Take a photo of the drawing with your phone and get it onto your laptop.
  3. Trace to SVG (3 mins): Open SVGcode (free, no account), drop in the photo, and download the SVG. It traces in black and white. In Illustrator, Image Trace → Expand → Export as SVG does the same.
  4. AI Web Integration (20 mins): Prompt Gemini/Claude to embed the SVG code directly into their live poster web markup:

    “Help me integrate this raw inline <svg> for my headline into my poster generator. Style it to dynamically resize with the browser viewport while pairing it with an expressive Google Variable Font for the body text.”

  5. (Optional) Animate your SVGs.

05Split critique

“Peer-Testing Fair”

To avoid student fatigue during large-group presentations:

  1. Setup: Divide class into Group A and Group B.
  2. Round 1 (10 mins):
    • Group A opens their live GitHub Pages sites on their laptops and stays at their station.
    • Group B acts as interactive testers, moving around the room, playing with the controls, dragging sliders, or triggering API hooks.
    • Instructors (Broderick & Mirko) split the room to conduct targeted, 2-minute micro-critiques with each student.
  3. Round 2 (10 mins): Swap roles. Group B presents, Group A tests.

06Variable fonts

Curated cheat sheet

  • Recursive — wght, CASL, CRSV, MONO, slnt — Expressive tech UI, casual vs. strict code, interactive hero text
  • Fraunces — wght, opsz, WONK, SOFT — Warm editorial, eccentric headlines, dynamic optical contrast
  • Tilt Neon / Tilt Warp / Tilt Prism — XROT, YROT, wght — 3D-feeling kinetic banners, hover-reactive typography
  • Bitcount — Pixel size, grid variations, stem options — Algorithmic posters, retro/gaming interfaces, data feeds
  • Roboto Flex — 12+ fine-grained parametric axes — Precision typographic tuning across screens
  • Decovar: play with the font at v-fonts and download it on GitHub — Multi-axis modular geometric deformations — Wild display experiments, generative decorative type

More variable fonts: Google Fonts · v-fonts.com

GitHub font download instructions

  1. Click the font's "on GitHub" link.
  2. Open the fonts folder (for Tilt Prism: fonts → variable; Danfo and Ojuju open straight to the file).
  3. Click the font file:
    • Amstelvar: Amstelvar-Roman[…].ttf
    • Decovar: DecovarAlpha-VF.ttf
    • Tilt Prism: TiltPrism[XROT,YROT].ttf
    • Danfo: Danfo[ELSH].ttf
    • Ojuju: Ojuju[wght].ttf
  4. Click the download button (↓) at the top right of the file view.
  5. Move the downloaded .ttf into your project repo folder.
