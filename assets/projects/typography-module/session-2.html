Session 2: Prototyping & Generating the Web Engine

Goal: Translate design rules and typographic hierarchy into programmatic logic using AI as a co-developer, exclusively focusing on cross-platform web technologies.

01Overview

5.2 · Wed Sep 30 · in person

  • UI/UX Refinement: Prompt the AI to upgrade the initial paper sketches into high-fidelity working example thumbnails for the web app interface.
  • Prompting the Build:
    1. Use your prompt to direct the AI to code the frontend of the web application.
    2. Prototype early parametric layouts directly in the browser using HTML/CSS/JavaScript or web-based code sandboxes to ensure cross-platform compatibility (PC/Mac).
  • Input vs. Output Paradigm: Define how the tool functions. Will it take text and randomize a grid? Will the user upload an image and have the tool extract a color palette?
  • Format Selection & Export: The application MUST support human-testable output formats (SVG and/or PDF). This ensures that the AI-generated layouts are not dead-ends, but rather scalable, pure-vector math that can be opened, manually edited, and refined later in Adobe Illustrator or other professional post-production software.

02In class

100 minutes

  • 20 min: Reviewing and critiquing the generated Markdown plans.
  • 40 min: Utilizing browser-based environments (local HTML/css/JS single page file) to validate programmatic layout and typographic scaling assumptions, ensuring full compatibility for both PC and Mac users. no code snippets. Full page html please.
  • 40 min: Initiating the AI code generation for the web application frontend:
    1. Write your prompt in natural language.
    2. Upload the natural language prompt to Gemini and have it reformatted as an llm prompt.
    3. Have gemini work up your project based on your two markdown files, poster image, and the refined prompt.

03Homework

5–6 hours

  • 2 hours: Passing code back and forth with the AI to establish basic functionality (e.g., uploading an image or inputting text).
  • 2 hours: Implementing robust export functionality:
    1. Ensure the app exports valid SVG or PDF files.
    2. Download test files.
    3. Open them in Adobe Illustrator to verify they are editable.
  • 1–2 hours: Identifying and documenting the first wave of structural bugs or visual failures in the output, paying special attention to typography rendering in the browser versus the exported vector file.
