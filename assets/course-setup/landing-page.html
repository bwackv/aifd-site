creating Your Course Landing Page

Using Copilot to create a GitHub Pages landing page · ART 3041

01What you're making

One file, named index.html. Click here for an example.

You're making your course landing page for the semester. The file must be named/saved as: index.html. Your course landing page provides your information + links to all of your course work in Art 3041: AiFD.

You are not typing the HTML yourself. You are telling Copilot what to build, then checking what comes back, noting what you want changed, handing it back to Copilot until you get what you want. This type of working process approximates how you will work with a.i. throughout the semester.

02The prompt

Answer the red parts first, then paste.

This is what you hand Copilot. Everything in red brackets is yours to decide — write those answers out in a notes program first, then swap them into the block below. Everything else stays as it is.

  • [your name] — spelled the way you want it read.
  • [your email] — the address you want on a public page.
  • [how it should look] — plain, loud, quiet, technical, funny. Name it in your own words, and name colors: dark blue and magenta, gray scale, etc. Find a website you like and describe that, or a style you're into right now (“grunge”, “cyberwave”, “art deco”). You can say “make it as if Beyoncé made it.” No wrong answer.
  • [typography] — serif or sans-serif, and anything else you want about the type.

The project list is already filled in for you. It will grow through the semester; you'll rename and add to it later.

Paste into Copilot 
Build me a single web page. Give me back one complete HTML file
named index.html

Rules:
- One file only. The CSS and the JavaScript go inside the HTML file.
- It has to work on a phone as well as a laptop.
- Use my real text. No placeholder text.

The page:
- Heading: A.I. FOR DESIGNERS — [your name]
- Under it: ART 3041 · Fall 2026
- Under that: [your email], as a mailto link
- Then a list titled Work, numbered 01 to 07:
    01 Custom Instructions
    02 A Style Guide for Your AI
    03 Design a ___
    04 Commute Story
    05 Become a Crea(i)tive Director
    06 Experimental AI Interface
    07 Open
  Each row is a link with nothing in it yet. I will fill
  them in as the semester goes.

How it should look: [how it should look]

Typography specifications: [typography]

Give me a downloadable HTML file named index.html.

The one-file rule is the one that matters for publishing: a page that depends on other files will not work on GitHub Pages.

03Check it

Before you publish.

  • Open index.html by double clicking it.
  • Narrow the window until it is phone width. Does it still read?

Then change it

  • One change at a time.
  • Say what is wrong, not that it should be better. “The course name is smaller than the course number” beats “make it nicer”. The body text is too large, reduce it. Change X color. Add borders around Y. Etc. Really go in with an eye for detail and list out changes you want.
  • Ask for the whole file back each time, not a snippet to splice in.
  • If a change makes it worse, say so and go back to the version you had.
