01Copilot

Sign in with your CUNY Login, set it up, then write your own custom instructions.

Sign in

  1. Go to copilot.cloud.microsoft.
  2. Enter your CUNY Login — firstname.lastname##@login.cuny.edu, not your Baruch email.
  3. Enter your CUNY Login password.
  4. Approve the sign-in in the Microsoft Authenticator app on your phone.
  5. At Stay signed in?, check Don't show this again and click Yes.

Set up

  1. Open Settings.
  2. Go to Personalization.
  3. Turn on Custom instructions.
  4. Turn on Saved memories.
  5. Click Edit instructions.

Custom instructions

Class time is set aside to write your own. A starting set:

  • Ask questions and propose a plan before producing anything.
  • Offer alternatives instead of agreeing by default.
  • State your uncertainty level, and name the tradeoff when there is one.
  • Ask before assuming a missing detail.
  • Don't invent facts or sources. Check every URL before linking it.
  • Always comment code with plain-English descriptions of what it's doing.
  • Always put HTML, CSS, and JavaScript in one HTML file.
  • Use bullet points for summaries.
  • Don't write essays/overly-winded responses.
