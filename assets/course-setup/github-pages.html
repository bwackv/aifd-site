Putting your page online · ART 3041

01GitHub Pages

A free way to put a web page online. Do the steps in order.

Make a GitHub account

  1. Go to github.com and click Sign up.
  2. Enter an email address, a password, and a username, then finish the steps.
  3. Open the email GitHub sends you and click the link inside to verify your address.

Make a new repository

A repository is the folder that holds your project's files.

  1. Click New to start a new repository.
  2. Give it a name.
  3. Keep it set to Public.
  4. Check Add a README file.
  5. Click Create repository.

If you name the repository exactly yourusername.github.io, the page publishes at the top-level address https://yourusername.github.io/ instead of under a repository name.

Add your page

  1. In the repository, click the + button, then Create new file.
  2. Name the file index.html.
  3. Paste in the HTML you made in your landing page.

    To get the code for your HTML, open it in the browser, then right click inside of the document and go to View Page Source.

    It will open the code in a new browser tab. Select all of the code, copy it (cmd-C, or go to Edit → Copy). Finally, paste the code into the large text area in GitHub (it will say Enter file contents here).

  4. Click Commit changes to save it. (Committing means saving your change into the repository.)

index.html is what loads when someone opens your site's address with nothing after the last slash — https://yourusername.github.io/your-repo/. Every other file needs its own name in the address: about.html only opens at https://yourusername.github.io/your-repo/about.html.

Turn on Pages

  1. Open the repository's Settings.
  2. In the left sidebar, click Pages.
  3. Under Build and deployment, set Source to Deploy from a branch.
  4. Set Branch to main and the folder to / (root).
  5. Click Save.

Get the link

  1. Wait about a minute, then refresh the page.
  2. It shows Your site is live at https://yourusername.github.io/your-repo/.
  3. Click that link to visit your page.

After any change you commit, it takes about a minute for the live page to update.

02Adding your Design a (blank) assignment

Every project this semester lives in this same repository, next to index.html.

  1. In the repository, click +, then Create new file.
  2. Name it design-a.html. Leave it next to index.html — not inside a folder.
  3. Get the code the same way you did before: open your Design a ____ file in the browser, right click, View Page Source, select all, copy, and paste it into Enter file contents here.
  4. Click Commit changes.
  5. Now link to it from your homepage. Back in the repository, click index.html, then the pencil icon to edit it.
  6. Find the 03 Design a ___ row of your Work list. Copilot built each row as an empty link, so it looks like this: 
    <a href="">Design a ___</a>
  7. Type the file name inside the empty quotes, so it reads: 
    <a href="design-a.html">Design a ___</a>
    Nothing else on the line changes.
  8. Click Commit changes.
  9. Open your live address and click that row. It opens at https://yourusername.github.io/your-repo/design-a.html, the way the note above describes.

Every project after this one works the same way: add the file, then fill in its row.
